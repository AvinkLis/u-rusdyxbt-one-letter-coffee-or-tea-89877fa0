An entry for the make.fun competition
[One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

The program writes exactly one letter to `entry.txt` in the output
directory (`$MAKEFUN_OUTPUT_DIR` or `/output`): the competition allows one
letter and nothing else — no word, no explanation, no punctuation, not even
a newline — where A stands for coffee and B stands for tea.

## Run

```sh
node main.ts
```

Requires Node 22 or later. Standard library only, no network access.
Running it twice writes byte-identical output.
